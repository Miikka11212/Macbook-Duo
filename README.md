# MacBook Duo

让界面随屏幕一起展开。面向 MacBook 的原生桌面视觉实验：通过铰链角度驱动渐进毛玻璃、透视缩放、柔和黑边渐变与 RGB 色散。桌面边缘逐渐融入外围黑色，展开终点恢复清晰原图。

## 启动

日常使用请打开 `/Applications/MacBook Duo.app`，或双击项目目录内的 `Start MacBook Duo.command`。不要直接从 iCloud 同步的桌面目录运行开发构建。项目无第三方依赖，需要 Apple Silicon、macOS 14 或更新版本。已使用本机签名构建；未经过 Developer ID 公证。

```sh
./scripts/build.sh
./scripts/install.sh
open '/Applications/MacBook Duo.app'
```

只有 Command Line Tools 也可以构建，无需安装完整 Xcode。构建脚本在源码未变化时复用已有应用，避免无意义地改变签名；应用运行时拒绝覆盖构建。如有 Apple Development / Developer ID 证书，可用 `DUO_SIGN_IDENTITY="证书名称" ./scripts/build.sh` 指定稳定签名。应用使用 Swift 5 语言兼容模式，以当前 Swift 编译器编译。

## 使用

1. 点击「导入桌面截图」选择 PNG、JPEG、HEIC 或 TIFF；未导入时可使用内置示例桌面。
2. 用「手动模拟」滑块预览 0°–180° 的视觉变化，或切换到「真实铰链」。
3. 在常用展开姿势按 ⌘⇧K，保存真实铰链角度作为终点。设置中的「保存当前」保存当前选中的角度来源，便于手动调试。最小终点 20°。
4. 点击「全屏调试」将截图效果覆盖到内置屏幕。⌘H 隐藏或恢复控制面板，⌘⇧Esc 随时结束。
5. 保持「开盖后自动恢复」开启（默认开启）。成功开启实时效果后，应用会记住这个状态；合盖或显示器休眠时暂停捕获，开盖后自动重连内置屏幕和铰链传感器。请保持应用在菜单栏运行。
6. 点击「开启实时桌面」，在 macOS 提示中授权屏幕录制。若之前拒绝过，请到系统设置 → 隐私与安全性 → 屏幕与系统音频录制，开启 MacBook Duo；按系统提示退出并重新打开应用，再重试。

实时模式自动使用真实角度，不能通过手动滑块改变。动画进度为 `clamp(角度 / 保存终点, 0, 1)`，加上平滑插值。在终点移除覆盖，原桌面恢复正常显示。

菜单栏图标、Dock 右键菜单均提供「打开设置」「开关实时效果」「停止效果并返回设置」「保存当前铰链终点」。关闭设置窗口后，应用仍保留在菜单栏。

| 快捷键 | 功能 |
| --- | --- |
| ⌘⇧G | 开关实时效果 |
| ⌘⇧Esc | 停止效果并返回设置 |
| ⌘⇧K | 保存当前真实铰链角度为终点 |
| ⌘H | 仅在截图调试期间，隐藏或恢复控制面板 |

## 实现与边界

- **铰链**：IOKit HID，Apple Vendor `0x05AC`，Sensor Usage Page `0x20`，Usage `0x8A`；以 30 Hz 读取 Feature Report 1，小端角度。当前机器已实测读通。此硬件接口并非 Apple 提供的稳定公开角度 API，其他型号可能没有传感器或读取失败；此时仍可手动模拟，并会停止实时效果。
- **渲染**：MetalKit + Core Image，共用同一个合成器渲染设置预览与全屏效果。渐变遮罩控制清晰/模糊区域，透视变换、羽化遮罩和 RGB 通道分离表现玻璃，边缘柔和渐变至黑色；「黑边柔和度」与「色散强度」可在调试设置中调整并自动保存；静止后暂停重复 GPU 绘制。
- **实时桌面**：ScreenCaptureKit，枚举包含隐藏窗口的应用列表，按进程与应用标识排除本应用，连同之后新建的覆盖窗口一起排除。无法确认当前进程已被排除时不会启动捕获，避免开盖时反复捕获自身、画面逐层变白。捕获 30 fps、宽度最高 1920 像素，不捕获音频。鼠标点击穿透覆盖层，光标保持系统原生绘制；中间动画状态下，透视画面位置与实际点击坐标不完全一致，建议在展开完成后操作。
- **多屏**：实时模式只处理 MacBook 内置屏幕，不影响外接显示器；内置屏幕不存在时拒绝启动实时模式。截图调试可回退至主屏幕。
- **合盖 / 开盖**：不阻止 macOS 休眠。默认开启「开盖后自动恢复」：休眠暂停捕获并保留实时效果的开启状态；系统、显示器和用户会话恢复后，等待内置屏幕与传感器就绪，自动建立新的捕获流。首个完整的新桌面帧到达后，补播约 0.65 秒的展开过渡，再持续跟随真实铰链。自动重连采用有上限的退避重试，不在后台反复弹权限框。系统尚未唤醒或安全锁屏界面期间无法由普通桌面应用绘制效果。
- **关闭与重启**：⌘⇧Esc 或「关闭实时效果」会清除自动恢复意图，之后开盖不会擅自重新开启。关闭设置窗口只隐藏面板；退出应用后，需要重新打开应用才能工作（未自动添加登录项）。应用重新启动会记住之前的开启状态；关闭自动恢复开关后，休眠将结束本次实时效果。
- **隐私**：不联网、不上传、不保存实时录制。导入的截图保存在 `~/Library/Application Support/MacBook Duo/desktop.png`，终点与质感设置保存在应用偏好设置中。
- **分发**：此构建为本机使用，未公证。重新签名或改变程序位置后，macOS 可能要求重新授权录屏。权限开关显示开启但仍被拒绝，可能是 TCC 保留了旧构建的代码哈希。先退出应用，再仅清除此应用的旧权限：`tccutil reset ScreenCapture studio.macbookduo.app`，然后从 `/Applications` 启动已验证的应用并重新授权。这不会清除截图或偏好设置。iCloud 桌面可能再次写入 FinderInfo，影响签名校验，因此可执行应用安装在 `/Applications`，源码仍保留在桌面。全局快捷键发生冲突时会提示，菜单始终可用。

## DMG 测试版分发

```sh
./scripts/package-dmg.sh '/Applications/MacBook Duo.app' "$PWD/dist/MacBook-Duo-1.0.0-arm64-test.dmg"
```

封装现有已验证的应用，不重新编译或改变签名。DMG 包含应用、Applications 拖拽入口和中英安装说明；不包含用户截图或偏好设置。脚本验证镜像校验和、镜像内应用签名及复制安装后的签名，并生成 SHA-256 校验文件。当前测试版为 arm64、macOS 14+，使用临时签名，尚未公证；首次运行可能需要接收者手动允许，实时效果需单独授权录屏。兼容的铰链传感器仍需按机型验证。

## 验证

```sh
./scripts/test.sh
./scripts/test-render.sh
open 'build/MacBook Duo.app' --args --render-check "$PWD/work/render-check"
```

测试覆盖休眠/屏幕/会话通知组合、重复唤醒、设备短暂断开恢复、停止取消待恢复任务、自动恢复关闭、重启状态恢复，以及 HID 报告解码、非法输入、角度归一化、终点夹取、过渡单调性；同时检查 GPU 图像尺寸、不透明合成、各过渡状态差异和展开终点逐像素还原。`--render-check` 导出 0°、60°、120° 的渲染 PNG，便于检查闭合、中间态与展开终点。实际录屏功能需要用户授予 macOS 权限；无权限时只验证拒绝后的恢复流程。

捕获排除回归检查（先退出应用，且已授予录屏权限）：

```sh
open '/Applications/MacBook Duo.app' --args --capture-check "$PWD/work/capture-check.json"
```

此检查会短暂显示洋红色测试窗口，再自动退出；不让机器休眠、不修改偏好设置、不保存桌面图像，只写入检查结果。三轮均先隐藏设置窗口，建立过滤器，再创建新的覆盖窗口；未过滤的对照捕获应包含测试色，应用过滤后的捕获应不含测试色。当前机器实测三轮均通过，旧的仅屏幕可见窗口查询三轮均遗漏自身进程，修复后测试色泄漏为 0。
